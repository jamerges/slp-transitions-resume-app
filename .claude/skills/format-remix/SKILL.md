# Format Remix

Two modes. Both depend on three documents — read them first:
1. `content/competitor-formats.md` — the pattern library + saved specimens
2. `content/voice-of-customer.md` — the reader's language and register rules
3. `content/style-guide.md` — James's voice

## Mode 1 — Generate (default)

Input: a topic (and optionally a platform: LinkedIn / Instagram carousel / blog / email).

1. Pick the 1-2 best-fit formats from the pattern library table. Say which and why in
   one line each — then commit to one unless asked for options.
2. Draft in that skeleton, with these non-negotiables:
   - **Never copy competitor phrasing.** The skeleton is structural (hook type, block
     order, CTA position) — every sentence is original and in James's voice.
   - **Numbers must be real.** Pull from `content/research-facts.md` or James's actual
     data (quiz aggregates, revenue). If the format needs a number that doesn't exist
     yet (e.g. income transparency before there's income), say so and shelve it —
     don't fabricate.
   - Run the register rules from the VoC doc (pain-mirroring quota, banned
     marketer-tells, permission-granting close).
   - Platform mechanics: LinkedIn — hook above the fold, short lines, identity
     paragraph at bottom, link in comments; carousel — one point per slide, hook
     card + CTA card; blog — FAQ block at the end, quiz CTA not product CTA.
3. Output: the draft, then a 3-line shipping note (best posting window, what to put in
   the first comment, what to repurpose it into next).

## Mode 2 — Dissect a specimen

Input: a pasted post (competitor's or James's own) that performed well.

1. Break it into a numbered skeleton (hook type → blocks → close), like the Lauren
   Braley specimen in `competitor-formats.md`.
2. Name *why* it works for the clinician audience (tie to VoC themes — skepticism of
   coaches, permission hunger, receipts-over-promises).
3. Append it to `content/competitor-formats.md` as a new specimen with date + source,
   and add a row to the pattern table if it's a genuinely new format.
4. Suggest one James-remix with real available data.

## Hard rules

- Structure is learnable; sentences are not. If a draft sentence could be mistaken
  for the source specimen's sentence, rewrite it.
- Every factual claim traces to `content/research-facts.md` (project rule).
- One format per asset. Frankenstein posts (hook from one, receipts from another,
  essay close from a third) read as AI soup.
