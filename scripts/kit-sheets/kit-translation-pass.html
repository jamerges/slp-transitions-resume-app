The translation pass

One page to hold beside the résumé. Every bullet answers three questions: how big was it, what did you do, what changed. Swapping nouns produces word salad; answering the questions produces evidence.

The swap, seen in the wild: “Orchestrated daily end-to-end client workflows for premium accounts, maintaining 100% data compliance.” It could describe a hotel concierge. Yours should name the size, the work and the result in words anyone can check.

Two tests for every line

  • The colleague test. If any SLP down the hall could have written it about their own year, it is a job description, not evidence. Cut it.
  • The ten-minute test. If you could not talk for ten minutes about the day behind that number without inventing anything, take the number down or the claim out.

The last pass before you attach it

  • Summary leads with the function and the years, not the credential
  • Title stays Speech-Language Pathologist; the translation is a function line under it
  • Every bullet has a number that could be checked
  • No ICD codes, modalities, billing or legal-charting language
  • EMR listed as a system you ran, beside Sheets, Zoom, the project tool you used
  • Three of the posting’s own requirement lines appear, in their words, up top
  • One page under ten years, two at most; file named Firstname-Lastname-Role.pdf
